# Goofy Goober

Goofy Goober is my first ever slack bot made using node.js and a hackclub Stardance guide.

# Commands:

• /goofy-goober-help
• /goofy-goober-ping
• /goofy-goober-catfact
• /goofy-goober-joke
• /goofy-goober-ranfact
• /goofy-goober-quote
• /goofy-goober-wotd
• /goofy-goober-riddle

# Daily Report:

Everyday at 6am (london/europe) this bot sends a message in the slack "#bots-spam" channel, it will follow this format:

## 🗞️ Goofy Goober DAILY REPORT:

(date using const d = new Date)


## Quote of the day:

(quote from api)


## Joke of the day:

(joke from api)


## Riddle of the day:

(riddle from api)


## Word of the day:

(word of the day from wotd api)


## Fact of the day:

(todays fact from api)
